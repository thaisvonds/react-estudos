# React | Estudos – DevQuest

Repositório destinado aos meus estudos em **React**, desenvolvidos durante o curso **DevQuest**.

Os projetos aqui representam **aulas e exercícios práticos**, utilizando tanto **JavaScript** quanto **TypeScript**, com foco na base do desenvolvimento front-end com React.

---

## Estrutura do repositório

Cada pasta representa uma aula ou exercício independente do curso.

Exemplo:
- `aula-componentes`
- `aula-props-ts`
- `aula-jsx-tsx`
- `exercicio-props`

---

## Tecnologias utilizadas

- React
- JavaScript
- TypeScript
- Vite

---

Repositório criado com foco em aprendizado contínuo e prática.
